嘉立创 3D 模型下载器 (JLC3D-Downloader)
一个基于 Python Tkinter 开发的桌面实用工具，通过元器件编号（如 C8734）快速从嘉立创 (JLC) 平台获取并下载对应的 STEP 格式 3D 模型。

项目特点
极简操作：输入编号，一键下载。

多线程处理：下载过程中界面不卡死，实时显示进度日志。

智能定位：下载完成后可一键打开文件夹并选中文件。

自动配置：自动记录你的下载路径首选项。

现代 UI：基于 Tkinter 优化，界面直观，兼容 Windows。
